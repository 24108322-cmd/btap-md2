BÀI NỘP - INTERACTIVE IMAGE GALLERY

Cấu trúc:
- index.html: giao diện HTML
- style.css: định dạng giao diện
- script.js: xử lý sự kiện mouseover/mouseout

Cách chạy:
1. Giải nén thư mục.
2. Mở index.html bằng trình duyệt.
3. Di chuột vào từng ảnh để xem ảnh và nội dung thay đổi.
4. Đưa chuột ra khỏi ảnh để hoàn tác.

Lưu ý:
- Ảnh trong bài đang dùng URL trực tuyến.
- Có thể mở F12 > Console để xem alt và source được in ra bởi console.log().
